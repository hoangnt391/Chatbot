# ASHNA AI CHAT

Phase 01 — React, TypeScript, Tauri 2 and Rust. Demo only; no live Ashna integration.

Install Node.js 22, Rust stable, Windows C++ Build Tools and WebView2. Run `npm install`, `npm run dev` or `npm run tauri dev`. Run `npm run build` to check frontend. Native packaging requires icons and enabling bundle configuration. For Android install SDK/NDK/JDK and run `npm run tauri android init` before building. Builds not yet verified. Local history is unencrypted; do not store sensitive data.
